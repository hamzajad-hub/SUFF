# Legal pages and operator handoff

`/privacy` and `/terms` contain substantive policies for the current SUF development preview. They are server-rendered and linked from the shared footer on login, public, private-shell, search, legal and missing-page views.

The operator label is **SUF project team**. Contact uses the repository's GitHub Issues page. The UI explains that issues are public and must not include credentials, private messages, or personal documents. Replace this route with the team's approved private contact address when supplied.

Policies describe actual local storage, temporary files, unauthenticated demo identities, bounded in-memory chat history, optional recovery/OAuth endpoints, and the limits of preview login and code execution. Fonts are served locally with their licenses; no analytics or advertising tracker is installed by this implementation.

Before public production launch, update these pages to match the real operator, contact, hosting, account/database storage and retention, uploads, moderation, providers and data handling. These pages do not claim legal certification or complete GDPR functionality. Do not add promises the application cannot fulfill.
